# PLAB 청구서 (tax.plab.life)

거래처에 링크로 보내는 청구서 페이지입니다.

- 거래처는 링크를 열어 청구서·입금 계좌를 확인하고, 정식 청구서를 인쇄·PDF로 저장할 수 있어요.
- 첫 거래라면 사업자등록증·통장사본을 직접 올리고, 문의를 남길 수 있어요.

| 구성 | 위치 | 역할 |
|---|---|---|
| 웹페이지 | 이 레포 (GitHub Pages) | `index.html`, `style.css`, `app.js`, `config.js` |
| 서버 | 구글 시트에 붙은 Apps Script | `apps-script/Code.gs` — 청구서 조회, 문의 저장, 서류 업로드, 슬랙 알림 |
| 데이터 | 구글 시트 'PLAB 청구서' | 청구서 · 품목 · 거래처 · 문의 탭 |
| 서류 | 운영팀 전용 드라이브 폴더 | 거래처가 올린 사업자등록증·통장사본 |

> 직인 이미지와 프랩 사업자등록증·통장사본은 공개 레포에 올리지 않습니다.
> 드라이브에 두고, 유효한 청구서 링크로 접속했을 때만 Apps Script가 내려줍니다.

---

## 1. 구글 시트 + Apps Script (최초 1회)

1. 회사 계정(plabsolution.com)으로 운영 공유 드라이브에 새 구글 시트 **PLAB 청구서**를 만듭니다.
2. 시트에서 **확장 프로그램 → Apps Script**를 엽니다. 기본 `Code.gs` 내용을 지우고 이 레포의 `apps-script/Code.gs`를 통째로 붙여넣은 뒤 저장합니다.
3. 드라이브에 아래를 준비합니다.
   - 거래처 서류를 모을 폴더 (예: `4. 회계/거래처 서류`) — **운영팀만 접근**
   - 직인 PNG 파일
   - 프랩 사업자등록증, 통장사본 파일
4. Apps Script **프로젝트 설정(톱니바퀴) → 스크립트 속성**에 추가합니다. ID는 드라이브 주소의 `/d/` 또는 `/folders/` 뒤 문자열입니다.

   | 속성 | 값 |
   |---|---|
   | `SLACK_WEBHOOK` | 세금계산서 요청 채널의 Incoming Webhook URL |
   | `DOCS_FOLDER_ID` | 거래처 서류 폴더 ID |
   | `SEAL_FILE_ID` | 직인 PNG 파일 ID |
   | `PLAB_BIZ_FILE_ID` | 프랩 사업자등록증 파일 ID |
   | `PLAB_BANK_FILE_ID` | 프랩 통장사본 파일 ID |

5. 편집기에서 함수 `setup`을 선택하고 **실행**합니다. 처음 실행할 때 권한 승인 창이 뜨면 허용합니다. 탭 4개와 예시 청구서가 만들어집니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 아래처럼 설정한 뒤 배포합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
7. 나온 웹앱 URL(`…/exec`)을 `config.js`의 `API_URL`에 넣고 커밋합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.
> 이렇게 하면 URL은 그대로 유지됩니다.

## 2. GitHub Pages + 도메인

1. 레포 **Settings → Pages**에서 아래처럼 설정합니다.
   - Source: *Deploy from a branch*
   - Branch: `main` / `(root)`
2. 가비아 **DNS 관리 → 레코드 추가**에서 아래 레코드를 넣습니다.
   - 타입 `CNAME`, 호스트 `tax`, 값 `plab-solution.github.io.`
3. Pages 설정의 Custom domain에 `tax.plab.life`가 들어가 있는지 확인합니다. 레포의 `CNAME` 파일이 넣어줍니다. 인증서가 발급되면 **Enforce HTTPS**를 체크합니다.

## 3. 청구서 보내는 법

시트 머리글 중 **파란 칸은 스크립트가 채우는 칸**이고, 회색 칸만 직접 적으면 됩니다.

1. **청구서** 탭 새 줄의 **거래처 상호** 칸에 상호를 적습니다.
   - 기존 거래처는 드롭다운에서 고르세요. 사업자번호·대표자가 자동으로 채워집니다.
   - 새 거래처는 상호를 그대로 입력하세요. 구분이 `신규 · 서류 대기`로 표시됩니다.
   - 문서번호(`PLAB-연도-순번`), 발행일(오늘), 지급기한(+7일), 상태(입금 대기), 링크도 함께 채워집니다. 이미 값이 있는 칸은 건드리지 않아요.
2. 건명과 금액(VAT 별도)을 적습니다.
   - **품목이 하나면** 청구서 탭의 금액 칸이면 충분해요.
   - **품목이 여러 개면** 품목 탭에 같은 문서번호로 줄마다 적어요. 품목 탭에 줄이 있으면 그쪽이 우선이에요.
3. `링크` 열의 주소를 거래처에 보냅니다.
4. 입금이 확인되면 상태를 **입금 완료**로 바꿉니다. **취소**로 바꾸면 링크가 막혀요.
5. 세금계산서를 발행하면 **세금계산서 발행일** 칸에 날짜를 적습니다. 거래처 화면의 진행 단계가 완료로 바뀌어요.

거래처 화면은 `청구서 확인 → 입금 → 서류 제출 → 세금계산서 발행` 네 단계로 보여요. 상태가 입금 완료인지, 거래처 탭에 서류가 있는지, 세금계산서 발행일이 적혀 있는지에 따라 단계가 자동으로 넘어갑니다.

금액 계산은 아래와 같습니다.
- 부가세 = (공급가액 − 할인) × 10%
- 합계 = 공급가액 − 할인 + 부가세

## 4. 신규 · 기존 거래처

**거래처** 탭이 거래처 명부입니다. 사업자번호가 기준이에요.

| 구분 | 조건 | 거래처가 보는 화면 |
|---|---|---|
| 신규 · 서류 대기 | 청구서에 사업자번호가 없음 | "프랩과 첫 거래네요" + 기초 정보 등록하기 |
| 신규 | 서류를 낸 뒤 거래 1건 | "기초 정보가 등록돼 있어요" |
| 기존 | 거래 2건 이상, 또는 등록 경로가 `기존 자료` | "다시 찾아주셔서 감사해요 · N번째 거래" + 지난 청구서 목록 |

- **사이트 이전부터 거래하던 곳**은 거래처 탭에 사업자번호 · 상호 · 대표자를 넣고, 서류 두 칸에 파일 링크나 `기존 보관`을 적으세요. 등록 경로가 `기존 자료`가 되어 첫 청구서부터 기존 거래처로 보이고, 서류를 다시 달라고 하지 않아요.
- 거래처가 사이트에서 서류를 내면 거래처 탭에 자동으로 추가되고(`사이트 제출`), 드라이브의 `상호_사업자번호` 폴더에 저장되며, 슬랙에 `:new: 신규 거래처 서류 제출`로 알림이 갑니다.
- 구분 · 첫 거래일 · 거래 건수 · 최근 청구일 · 누적 청구액은 시트를 고칠 때마다 다시 계산돼요. 숫자가 이상하면 메뉴 **PLAB 청구서 → 거래처 집계 새로고침**을 누르세요.
- 문의 슬랙 알림에는 `[신규]` / `[기존]`이 붙어요.

## 화면만 확인하기

`config.js`의 `API_URL`이 비어 있거나 주소 끝에 `?demo=1`을 붙이면 예시 데이터로 화면을 볼 수 있어요. 기존 거래처 화면은 `?demo=1&as=existing`, 서류 없는 기존 거래처는 `?demo=1&as=nodocs`, 입금 완료는 `&paid=1`, 세금계산서 발행 완료는 `&tax=1`을 붙여 확인할 수 있어요.
