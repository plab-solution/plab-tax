# PLAB 청구서 (tax.plab.life)

거래처에 링크로 보내는 청구서 페이지입니다.

- 거래처는 링크를 열어 청구서·입금 계좌를 확인하고, 정식 청구서를 인쇄·PDF로 저장할 수 있어요.
- 첫 거래라면 사업자등록증·통장사본을 직접 올리고, 문의를 남길 수 있어요.

| 구성 | 위치 | 역할 |
|---|---|---|
| 웹페이지 | 이 레포 (GitHub Pages) | `index.html`, `style.css`, `app.js`, `config.js` |
| 서버 | 구글 시트에 붙은 Apps Script | `apps-script/Code.gs` — 청구서 조회, 문의 저장, 서류 업로드, 슬랙 알림 |
| 데이터 | 구글 시트 'PLAB 청구서' | 청구서 · 품목 · 거래처 · 문의 탭 |
| 서류 | 운영팀 전용 드라이브 폴더 | 거래처가 올린 사업자등록증·통장사본 |

> 직인 이미지와 프랩 사업자등록증·통장사본은 공개 레포에 올리지 않습니다.
> 드라이브에 두고, 유효한 청구서 링크로 접속했을 때만 Apps Script가 내려줍니다.

---

## 1. 구글 시트 + Apps Script (최초 1회)

1. 회사 계정(plabsolution.com)으로 운영 공유 드라이브에 새 구글 시트 **PLAB 청구서**를 만듭니다.
2. 시트에서 **확장 프로그램 → Apps Script**를 엽니다. 기본 `Code.gs` 내용을 지우고 이 레포의 `apps-script/Code.gs`를 통째로 붙여넣은 뒤 저장합니다.
3. 드라이브에 아래를 준비합니다.
   - 거래처 서류를 모을 폴더 (예: `4. 회계/거래처 서류`) — **운영팀만 접근**
   - 직인 PNG 파일
   - 프랩 사업자등록증, 통장사본 파일
4. Apps Script **프로젝트 설정(톱니바퀴) → 스크립트 속성**에 추가합니다. ID는 드라이브 주소의 `/d/` 또는 `/folders/` 뒤 문자열입니다.

   | 속성 | 값 |
   |---|---|
   | `SLACK_WEBHOOK` | 세금계산서 요청 채널의 Incoming Webhook URL |
   | `DOCS_FOLDER_ID` | 거래처 서류 폴더 ID |
   | `SEAL_FILE_ID` | 직인 PNG 파일 ID |
   | `PLAB_BIZ_FILE_ID` | 프랩 사업자등록증 파일 ID |
   | `PLAB_BANK_FILE_ID` | 프랩 통장사본 파일 ID |

5. 편집기에서 함수 `setup`을 선택하고 **실행**합니다. 처음 실행할 때 권한 승인 창이 뜨면 허용합니다. 탭 4개와 예시 청구서가 만들어집니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 아래처럼 설정한 뒤 배포합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
7. 나온 웹앱 URL(`…/exec`)을 `config.js`의 `API_URL`에 넣고 커밋합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.
> 이렇게 하면 URL은 그대로 유지됩니다.

## 2. GitHub Pages + 도메인

1. 레포 **Settings → Pages**에서 아래처럼 설정합니다.
   - Source: *Deploy from a branch*
   - Branch: `main` / `(root)`
2. 가비아 **DNS 관리 → 레코드 추가**에서 아래 레코드를 넣습니다.
   - 타입 `CNAME`, 호스트 `tax`, 값 `plab-solution.github.io.`
3. Pages 설정의 Custom domain에 `tax.plab.life`가 들어가 있는지 확인합니다. 레포의 `CNAME` 파일이 넣어줍니다. 인증서가 발급되면 **Enforce HTTPS**를 체크합니다.

## 3. 청구서 보내는 법

1. **청구서** 탭 새 줄에 **거래처 상호**를 적습니다. 아래 칸이 자동으로 채워져요. 이미 값이 있는 칸은 건드리지 않으니 필요하면 고쳐 쓰세요.
   - 문서번호(`PLAB-연도-순번`), 발행일(오늘), 지급기한(+7일), 상태(입금 대기), 링크
   - 이어서 건명을 적고, 필요하면 할인·비고·거래처 대표자·거래처 사업자번호도 적습니다.
2. 금액을 적습니다. 금액은 모두 VAT 별도예요.
   - **품목이 하나면**: 청구서 탭의 **금액** 칸에만 적으면 끝이에요. 건명이 품목 이름이 됩니다.
   - **품목이 여러 개면**: **품목** 탭에 같은 문서번호로 품목명 · 수량 · 단가를 줄마다 적어요. 품목 탭에 줄이 있으면 청구서 탭의 금액 칸은 쓰지 않아요.
3. `링크` 열의 `https://tax.plab.life/?id=…`를 거래처에 보내면 됩니다. 링크가 비어 있으면 메뉴 **PLAB 청구서 → 링크 만들기**를 누르세요.
4. 입금이 확인되면 상태를 **입금 완료**로 바꿉니다. 거래처 화면에 즉시 반영돼요. **취소**로 바꾸면 링크가 막힙니다.

금액 계산 방식은 아래와 같습니다.

- 공급가액 = 품목 합계
- 부가세 = (공급가액 − 할인) × 10%, 원 단위 반올림
- 합계 = 공급가액 − 할인 + 부가세

거래처가 서류를 올리면 **거래처** 탭에 기록되고, 드라이브 폴더 `상호_사업자번호`에 저장되며, 슬랙으로 알림이 갑니다. 다음 청구서부터 같은 사업자번호면 "첫 거래" 안내가 나오지 않아요.

## 화면만 확인하기

`config.js`의 `API_URL`이 비어 있거나 주소 끝에 `?demo=1`을 붙이면 예시 데이터로 화면을 볼 수 있어요.
